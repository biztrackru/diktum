# Диктум Product Site Materials

Эта папка хранит очищенную интеграцию дизайн-пака для внешней продуктовой упаковки.

Файлы:

- `dictum-landing.dc.html` - лендинг-прототип Диктум.
- `dictum-sharing-copy.dc.html` - готовые тексты для README, Telegram и личного шаринга.
- `support.js` - runtime экспортера дизайн-макета, нужен для просмотра `.dc.html`.
- `screenshots/` - превью из дизайн-пака.

Как смотреть:

1. Открыть `dictum-landing.dc.html` или `dictum-sharing-copy.dc.html` в браузере.
2. Telegram уже подставлен: `https://t.me/+ByvsbIefhtkyZGIy`.
3. GitHub уже подставлен: `https://github.com/biztrackru/diktum`.
4. Перед публикацией заменить `#REPLACE_WITH_YOUR_ZIP_URL` и `[ссылка]` / `[link]` на сайт/дистрибутив.

Эти материалы не входят в trial-pack приложения. Trial-pack остается минимальным: только launchers, `START_HERE.txt`, `VERSION.txt`, `FEEDBACK_TEMPLATE.txt`, `app/`, `Inbox/`, `outputs/`.

Сырой handoff из `design_promo_pack/` не считается частью продукта и не должен попадать в git: там могут быть личные исходники и промежуточные файлы.
