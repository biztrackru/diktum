# Agent Handoff Template

Use this format when handing work back to another agent or the user.

## Summary

What changed and why.

## Files Changed

- `path/to/file` - short reason.

## Checks Run

- command - result.

## Not Checked

Anything important that was not verified.

## Risks

Known risks or edge cases.

## Next Suggested Task

One concrete next step with suggested write scope.
